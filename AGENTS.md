# GFL5R Foundry System — Project Guidelines

## Project Overview

Foundry VTT system for the **GFL5R** tabletop roleplaying game — a cyberpunk tactical RPG set in the *Girls' Frontline* universe, built on *Legend of the Five Rings*' roll-and-keep dice engine.

## Git Workflow

- **Always pull after a push.** Run `git pull --rebase` after every successful push (and before retrying a rejected push) — this workspace's repos move independently and the remote frequently has new commits or tags.
