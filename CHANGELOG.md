# Changelog

## 0.1.0 (In Development)

Initial release. Forked from L5R5E v1.13.4 and adapted for the GFL5R setting.

- Approach-based system (Power, Precision, Swiftness, Resilience, Fortune) replacing L5R5E rings
- 24-skill system across 4 groups (Combat, Fieldcraft, Technical, Social)
- Human/T-Doll character types with branching derived stats
- Discipline horizontal progression system (up to 5 disciplines, 3 ranks each)
- 9 technique types (Combat, Command, Conditioning, Electronic Warfare, Remolding, Science, Social, Street, Vehicle)
- Electronic warfare subsystem (EW Rating, Security Rating, Heat)
- Collapse/ELID/Parapluie condition trackers
- Weapon system with ideal range, threat, signature, and qualities
- T-Doll modules as equipment items
- Compendium packs built from GFL5R webapp data
