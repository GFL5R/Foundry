# GFL5R Foundry VTT System

A Foundry VTT game system for **GFL5R**, a near-future military sci-fi tabletop RPG combining the world of Girls' Frontline with a roll-and-keep dice engine.

## Attribution

This system is a fork of [L5R5E](https://gitlab.com/teaml5r/l5r5e) (v1.13.4) by Vlyan, Mandar, Carter, and Litasa. The original L5R5E system implements Legend of the Five Rings 5th Edition for Foundry VTT and is licensed under CC BY-NC-SA 4.0 by Edge Studio.

GFL5R game rules and content are developed at [gfl5r.org](https://gfl5r.org).

## Requirements

- Foundry VTT v13

## Installation

Install via manifest URL in Foundry VTT's system installer (URL TBD).
